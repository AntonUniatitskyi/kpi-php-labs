## 🚀 Як запустити проєкт локально

Для запуску підійде будь-яке стандартне середовище розробки з підтримкою PHP 8+ (XAMPP, OpenServer, MAMP тощо) або вбудований веб-сервер PHP.

**Швидкий запуск через консоль:**
1. Відкрийте термінал у папці з потрібною роботою (наприклад, `cd lab1`).
2. Запустіть локальний сервер командою:
   ```bash
   php -S localhost:8000
   ```
3. Відкрийте сторінку в браузері за адресою http://localhost:8000.
