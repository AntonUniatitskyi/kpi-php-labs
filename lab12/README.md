# Практична робота №12. Анімація, Canvas та інтерактивні елементи

**Варіант:** 12 — Каталог домашніх тварин / акваріумних риб
**Технологія:** Canvas

## Завдання варіанта

Декоративна міні-анімація «рибки, що плавають»: кілька об'єктів рухаються по синусоїді на Canvas, кількість рибок залежить від кількості записів у каталозі.

## Що реалізовано

- Каталог тварин: додавання запису (назва, вид) і видалення. Дані зберігаються в `localStorage` і не зникають після оновлення сторінки.
- Canvas-акваріум: одна рибка на один запис каталогу (не більше 30, щоб не навантажувати Canvas).
- Рух по синусоїді: `y = baseY + sin(x · frequency + phase) · amplitude`. У кожної рибки власні швидкість, амплітуда, частота, фаза, розмір і напрямок. Нахил тіла рибки обчислюється за похідною синусоїди, хвіст «виляє».
- Зв'язок з даними: після кожного додавання або видалення запису викликається `syncFish(pets)`. Нова рибка з'являється, зайва зникає, решта не «стрибає». Колір рибки залежить від поля `species`.
- Керування: кнопка «Старт / Стоп».
- Коректне завершення: `cancelAnimationFrame` при зупинці, автопауза, коли акваріум поза екраном (`IntersectionObserver`), статичний кадр для користувачів із `prefers-reduced-motion`.

## Структура проєкту

```
aquarium-catalog/
├── index.html     розмітка та підключення скриптів
├── style.css      стилі
├── data.js        дані каталогу, localStorage
├── aquarium.js    Canvas-анімація
├── main.js        рендер списку, форма, запуск
└── README.md
```

| Файл | Відповідальність |
|------|------------------|
| `data.js` | `SPECIES_COLORS`, масив `pets`, `loadPets()`, `savePets()` |
| `aquarium.js` | `createFish()`, `syncFish()`, `update()`, `drawFish()`, `drawFrame()`, `loop()`, `startAquarium()`, `stopAquarium()` |
| `main.js` | `render()`, `addPet()`, `removePet()`, обробник форми, перший запуск |

## Як запустити

1. Покласти всі файли в одну папку.
2. Відкрити `index.html` у браузері.

## Використані технології

HTML5, CSS3, JavaScript (Canvas 2D API, `requestAnimationFrame`, `localStorage`, `IntersectionObserver`). Без сторонніх бібліотек.
