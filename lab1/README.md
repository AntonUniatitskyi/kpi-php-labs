
# Практична робота №1

**Тема:** Розробка PHP-структур та вивід результатів у вебсторінку.  
**Домен:** Онлайн-опитування/анкети (Варіант 12).

## 🎯 Мета роботи
Ознайомитися з базовим синтаксисом мови програмування PHP: змінні та типи даних, масиви, умовні конструкції, цикли та функції. Навчитися змішувати PHP-код з HTML-розміткою.

## 🛠 Реалізований функціонал
Відповідно до умов Варіанта 12 було реалізовано:
1. **Масив даних:** Створено масив питань із полями `text` (текст питання), `type` (тип) та `answersCount` (кількість зібраних відповідей).
2. **Умовна логіка:** Якщо `type == 'multiple'`, запису присвоюється відповідна мітка («Питання з варіантами відповіді») та генерується відповідне HTML-поле.
3. **Функція форматування:** Написана типізована функція для виведення заголовка питання.
4. **Агрегатний показник:** Обчислено та виведено сумарну кількість відповідей по всіх питаннях.
