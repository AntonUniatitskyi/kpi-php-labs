# Практична робота №3

**Тема:** Основи об'єктно-орієнтованого програмування у PHP: класи, повторне використання коду.  
**Домен:** Онлайн-опитування/анкети (Варіант 12).

## 🎯 Мета роботи
Навчитися створювати та використовувати класи й об'єкти в PHP; опрацювати властивості, методи та конструктори класів; освоїти базове успадкування (через `extends` та виклик `parent::`); навчитися організовувати код у власні прості бібліотеки — окремі файли з класами й функціями, підключені через `require_once`.

## 🛠 Реалізований функціонал
Відповідно до умов Варіанта 12 було реалізовано:
1. **Базовий клас `Question`:** Створено клас із захищеними (`protected`) властивостями `text` (текст питання) та `type` (тип питання). Реалізовано конструктор для їх ініціалізації та метод `getInfo()`, що повертає базовий текстовий опис об'єкта.
2. **Похідний клас `MultipleChoiceQuestion`:** Успадковує базовий клас `Question`. Додає власну властивість `options` (масив варіантів відповідей). Перевизначає метод `getInfo()`, викликаючи всередині `parent::getInfo()` і доповнюючи результат інформацією про кількість доступних варіантів.
3. **Клас-менеджер `Survey`:** Створено клас для управління колекцією питань. Містить масив об'єктів та реалізує методи додавання нового питання (`addQuestion()`), підрахунку кількості питань за типом (`countByType()`) та отримання всього списку (`listAll()`).
4. **Бібліотека функцій:** В окремому файлі створено допоміжні функції: `formatOptions()` для форматування масиву варіантів у HTML-список та `validateAnswer()` для перевірки, чи входить надана відповідь до списку допустимих варіантів.

## 💻 Структура файлів
Логіку проєкту розділено на окремі файли для повторного використання коду:
- `classes/Question.php` — опис базового класу сутності.
- `classes/MultipleChoiceQuestion.php` — опис похідного класу.
- `classes/Survey.php` — опис класу-менеджера.
- `lib/functions.php` — бібліотека допоміжних функцій, не прив'язаних до класів.
- `index.php` — головний скрипт, який підключає класи та бібліотеку через `require_once`, створює об'єкти, додає їх у менеджер і виводить результати у вигляді HTML-сторінки.
