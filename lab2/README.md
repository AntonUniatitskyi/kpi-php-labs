# Практична робота №2

**Тема:** Взаємодія вебзастосунку з користувачем: форми, валідація, локальне сховище браузера .  
**Домен:** Онлайн-опитування/анкети (Варіант 12).

## 🎯 Мета роботи
Навчитися обробляти дані HTML-форм у PHP через суперглобальні масиви `GET` і `POST`, освоїти серверну валідацію введених даних і повторне відображення форми з повідомленнями про помилки. Додати клієнтську валідацію засобами HTML5 та JavaScript, а також навчитися зберігати й відновлювати стан інтерфейсу за допомогою `localStorage` браузера.

## 🛠 Реалізований функціонал
Відповідно до умов Варіанта 12 було реалізовано:
1. **HTML-форма:** Створено форму для створення нового питання з полями `questionText` (текст питання), `type` (випадний список типів) та `options` (поле для варіантів відповідей).
2. **Серверна валідація (PHP):** Реалізовано перевірку обов'язковості заповнення полів. Додано специфічне правило: якщо обрано тип `multiple`, поле `options` повинне містити щонайменше два варіанти . У разі помилок форма відображається повторно зі збереженими введеними даними, які виводяться через `htmlspecialchars()` для захисту від XSS .
3. **Клієнтська валідація (JavaScript):** Додано перевірку перед відправкою форми. Якщо умови не виконуються, відправка блокується за допомогою `event.preventDefault()` і виводиться відповідне повідомлення без перезавантаження сторінки .
4. **Локальне сховище (localStorage):** Реалізовано збереження чернетки форми створення питання при кожному введенні тексту . Якщо випадково закрити вкладку або перезавантажити сторінку, введені дані автоматично відновлюються. Після успішного збереження питання чернетка очищається.

## 💻 Файли
- `index.php` — основний скрипт, що містить HTML-форму, PHP-обробник із серверною валідацією та JS-скрипти для клієнтської валідації й роботи з `localStorage`.
